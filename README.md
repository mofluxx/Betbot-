# ⚡ BetBot

Sportwetten-Helfer mit Live-Quoten: Value Bets, Surebets, Prognose-Modelle und Wett-Tracker.

**Web-App:** https://mofluxx.github.io/Betbot-/

| Bereich | Inhalt |
|---|---|
| 📡 Live | Live-Quoten (The Odds API), Value Bets mit Kelly-Einsatz, Surebets, Quoten-Vergleich |
| 🧮 Rechner | Value-Check, Buchmacher-Marge, faire Quoten |
| 📊 Prognose | Poisson (Tore), Elo (Sieger) |
| 📒 Tracker | Wetten, ROI, Trefferquote, monatliches Verlustlimit |
| ⚙️ Setup | API-Key, Ligen, Märkte, Buchmacher, Filter |

## Start
1. Gratis-Key holen: https://the-odds-api.com (500 Credits/Monat)
2. Web-App öffnen → **Setup** → Key eintragen → Ligen wählen
3. **Live** → **Live scannen**

Der Key wird nur im Browser des Geräts gespeichert, nicht im Code.

## Python-Version (`python/`)
Läuft dauerhaft am PC und schickt Treffer per Telegram. Anleitung: `python/ANLEITUNG.html`.
