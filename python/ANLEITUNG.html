⚡ WettBot – Anleitung

Live-Quoten-Scanner · Value Bets · Surebets · Telegram-Alarm

1 · Python installieren

  • Windows: python.org/downloads → bei Installation „Add Python to PATH“ anhaken
  • Keine weiteren Pakete nötig
  • Mac-Fehler „SSL certificate“: einmal Install Certificates.command im Python-Ordner starten

2 · Demo testen (ohne Key)

python wettbot.py --demo
Windows: Ordner öffnen → in Adresszeile cmd → Enter. Öffnet bericht.html mit Fantasie-Quoten.

3 · Live-Quoten freischalten

  1. the-odds-api.com → kostenlosen Plan wählen → Key kommt per Mail
  2. config.env mit Editor öffnen → ODDS_API_KEY=dein_key
  3. Start: python wettbot.py oder Doppelklick auf start_windows.bat
Gratis: 500 Credits/Monat. 1 Liga × 1 Markt = 1 Credit pro Scan. Der Bot teilt die Credits automatisch bis Monatsende ein (Standard: 3 Ligen ≈ alle 4–5 Std.).

4 · Telegram aufs Handy (optional)

  1. Telegram → @BotFather → /newbot → Namen wählen → Token kopieren
  2. Deinem neuen Bot irgendeine Nachricht schreiben
  3. Im Browser: api.telegram.org/bot<TOKEN>/getUpdates → Zahl bei "chat":{"id": = Chat-ID
  4. Beides in config.env eintragen → testen: python wettbot.py --telegram-test

So rechnet der Bot

p_fair = (1/Q_Pinnacle) / Σ(1/Q)Value = p_fair · Q_dein − 1 Kelly = (p·Q − 1)/(Q − 1)Surebet: Σ(1/Q_beste) < 1
  • VALUE Dein Buchmacher zahlt mehr als die faire Quote (Pinnacle ohne Marge bzw. Konsens)
  • SUREBET Beste Quoten verschiedener Buchmacher ergeben sicheren Gewinn
  • Jede Value-Meldung landet in signale.csv (Excel) → Spalte „Ergebnis“ selbst ausfüllen

Ehrlich & wichtig

  • Bot meldet nur – Wetten gibst du selbst ab (automatisches Wetten verstößt gegen AGB der Buchmacher)
  • Value-Wetten lohnen sich erst über hunderte Wetten; Verlustphasen sind normal
  • Buchmacher limitieren Gewinner-Konten → Surebets fallen schnell auf
  • Quote vor Abgabe immer prüfen – sie kann sich seit dem Scan geändert haben
  • Nur Anbieter auf der GGL-Whitelist (deutsche Lizenz) · nur Geld, dessen Verlust okay ist
